# ToDesktop UI Clone

This project is a simple clone of the landing page of **ToDesktop (https://www.todesktop.com)**.  
I built it to revise my fundamentals of **HTML** and **Tailwind CSS**, ensuring I stay sharp with the core concepts that power modern frontend development.

---

## 🚀 Features
- Fully responsive layout  
- Clean Tailwind CSS architecture  
- Simple, readable, revision-friendly code  
- No frameworks — pure HTML + Tailwind  

---

## 📦 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/muhammadhussain1911/cloned-todesktop-web.git
```
### 2. Navigate into the Project
```bash
cd cloned-todesktop-web
```
### 3. Install Dependencies (if using Tailwind CLI)
```bash
npm install
```
### 4. Run Tailwind in Watch Mode
```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```
### 5. Open the Project
Simply open `index.html` in your browser.
